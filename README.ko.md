# Folder Board

[English](README.md) | 한국어

**키보드 중심의 옵시디언 네이티브 2D 폴더 탐색기.**  
좁은 좌측 탐색기를 오르내리지 않고 볼트 전체를 다단 보드로 한눈에 보며, 키보드 들고 이동·드래그 정렬·우측 분할 빠른 편집까지 한 화면에서 끝낼 수 있습니다.

> **데스크톱 전용** · Obsidian `1.5.0+` 지원 · **한국어 / English 자동 감지** (설정에서 수동 선택 가능)

---

## 핵심 기능 한눈에 보기

- **3가지 레이아웃 모드 (`Flow` · `Vertical` · `Horizontal`)** — 깔끔한 연속 다단 트리(`Flow`, 기본)와 경계 드래그로 자유 분할하는 카드 그리드(`Vertical` / `Horizontal`)를 지원합니다. 각 모드마다 폴더 순서·열 수·카드 크기를 독립적으로 기억합니다.
- **마우스 없는 빠른 편집 루프 (`Space` → `Space`/`Tab` → `Esc`)** — `Space`를 누르면 우측에 옵시디언 진짜 분할 편집기가 열려 라이브 프리뷰와 모든 커뮤니티 플러그인이 그대로 동작합니다. `Space` 한 번 더(또는 `Tab`)로 바로 입력하고, `Esc`로 보드 복귀 → `Esc`로 닫기까지 키보드만으로 완결됩니다.
- **압도적으로 빠른 파일 정리(트리아지)** — `Option/Alt + 방향키`로 항목을 들고 이동(키를 떼면 드롭), `Option/Alt + 1~9`로 N번째 카드로 원키 이동, `Shift + ↑/↓` 범위 선택 및 `⌘/Ctrl + C / X / V / Z`를 지원합니다.
- **좌측 탐색기 완전 대체** — 보드 탭 자동 고정(`Pin`), 보드 진입 시 좌측 패널 스마트 자동 접기, 상단 **볼트 전환기(`볼트명 ⌄`)**, **북마크 드롭다운(`B`)**, **옵시디언 설정(`⚙️`)**까지 보드 안에서 바로 해결합니다.
- **옵시디언 네이티브 외형 동기화** — 기본 파일 탐색기의 아이콘과 색상(`material-icon-theme` 등 커뮤니티 아이콘 플러그인 포함)을 자동 미러링하며 **Minimal · Baseline · Things** 등 테마와 자연스럽게 어우러집니다.

## 3가지 레이아웃 모드

| 모드 | 추천 용도 | 주요 조작 |
| --- | --- | --- |
| **Flow** *(기본)* | 볼트 전체를 깔끔한 연속 다단 트리로 한눈에 탐색 | 열 사이 드래그로 다단 너비 조절 · 폴더 하단 호버로 `소(4) / 중(15) / 대(1열)` 선택 및 최대 `200줄` 드래그 · 대용량 폴더 내부 부드러운 휠 스크롤 |
| **Vertical** | 세로 스크롤 기반의 2D 카드 대시보드 | 열 사이 드래그로 `1~6열 분할` · 카드 하단 드래그로 `1/4 ~ 전체 높이` 조절 (더블클릭으로 `1/2 ↔ 전체` 토글) |
| **Horizontal** | 칸반 스타일 가로 스크롤 카드 보드 | 화면 너비에 정확히 `1~6열` 맞춤 + 초과분 가로 스크롤 · 카드 하단 드래그로 `1/4 ~ 전체 높이` 조절 |

- **폴더 순서 1회 정렬 (`A↓Z`)**: 툴바의 폴더 정렬 버튼으로 현재 모드의 폴더를 `이름순 · 역순 · 항목 많은 순 · 최근 수정 순`으로 1회 정리할 수 있으며, 정렬이 고정되지 않아 직후에도 마음대로 드래그 배치할 수 있습니다.

## 주요 단축키

보드 안에서 **`?`**를 누르거나 **설정 → Folder Board** 하단에서 전체 단축키 치트시트를 언제든 볼 수 있습니다.

| 분류 | 단축키 | 동작 |
| --- | --- | --- |
| **탐색 & 열기** | `↑` `↓` `←` `→` | 항목 · 카드 · 인접 열 이동 (첫 카드 최상단 `↑` → 검색창 포커스) |
| | `1`~`9` / `⌘/Ctrl + ←/→` | N번째 카드로 점프 / 첫 번째 · 마지막 카드로 점프 |
| | `Enter` / `⌘/Ctrl + Enter` | 노트 열기 · 폴더 진입 / 새 탭에서 열기 |
| | `Backspace` | 상위 폴더로 이동 |
| | `⌘/Ctrl + F` 또는 `/` | 보드 내 검색 |
| | `B` / `?` | 북마크 메뉴 열기 / 단축키 도움말 열기·닫기 |
| **빠른 편집 & 접기** | `Space` | **파일**: 1회 미리보기 · 2회 편집 커서 진입 / **폴더**: 접기·펼치기 |
| | `Tab` / `Esc` | 우측 편집기 커서 진입 / 보드로 복귀 (`Esc` 2회 닫기) |
| | `[` / `]` | 포커스 폴더 하위 일괄 접기 / 펼치기 |
| **파일 정리 & 편집** | `Option/Alt + 방향키` | 항목 들고 이동 (키를 떼면 드롭) |
| | `Option/Alt + 1`~`9` | N번째 카드로 원키 이동 |
| | `Shift + ↑/↓` / `⌘/Ctrl + A` | 범위 다중 선택 / 현재 카드 전체 선택 |
| | `⌘/Ctrl + C / X / V / Z` | 복사 / 잘라내기 / 붙여넣기 / 마지막 이동 되돌리기 |
| | `N` / `Shift + N` | 포커스 폴더에 새 노트 / 새 폴더 생성 |
| | `F2` 또는 `R` / `⌘/Ctrl + ⌫` | 제자리 이름 바꾸기 / 휴지통으로 삭제 |
| **카드 순서** | `Shift + ←/→` 또는 헤더 드래그 | 카드 순서 변경 (모드별 독립 저장) |

## 여는 방법

- **기본 탐색기 상단 버튼**: 좌측 파일 탐색기 툴바의 격자 아이콘(`⊞`) 클릭 (`⌘/Ctrl + 클릭` 시 현재 노트의 폴더로 바로 열기)
- **리본 아이콘**: 좌측 리본의 Folder Board 아이콘 클릭
- **커맨드 팔레트 (`⌘/Ctrl + P`)**: `폴더 보드 열기` 또는 `Open 2D Folder Board` 실행 (설정에서 원하는 한글 별칭 자유 지정 가능)

## 설치 방법

### 수동 설치
1. 최신 릴리스(또는 `plugin/` 빌드 결과)에서 `manifest.json`, `main.js`, `styles.css` 3개 파일을 준비합니다.
2. `<내 볼트>/.obsidian/plugins/folder-board/` 폴더를 생성하고 위 3개 파일을 복사합니다.
3. 옵시디언을 리로드한 뒤 **설정 → 커뮤니티 플러그인**에서 **Folder Board**를 활성화합니다.

### 소스에서 직접 빌드
```bash
cd plugin
npm install
npm run build
```

## 주요 설정

- **언어 (Language)**: `자동` 선택 시 옵시디언이 한국어면 한국어, 그 외 모든 언어에서는 영어로 동작하며 `English` / `한국어` 수동 선택도 가능합니다.
- **커맨드 팔레트(⌘P) 열기 별칭**: 한영 전환 없이 바로 찾을 문구 등록 (재시작 없이 즉시 반영).
- **폴더 보드 탭 자동 고정 (Pin)**: 노트를 열어도 보드가 사라지지 않고 옆 탭에서 열리도록 고정 (보드 상단 핀 버튼으로도 원클릭 토글).
- **좌측 패널 자동 접기**: 폴더 보드를 볼 때만 좌측 탐색기를 자동으로 접어 화면을 넓히고, 다른 노트로 나가면 자동 복원 (`Space` 분할 편집 중 및 수동 접힘 상태 존중).
